# Batalla_el_Castillo_Infinito
Proyecto académico desarrollado en Java con Spring Boot que modela el sistema de batallas del Castillo Infinito. Incluye arquitectura limpia, controladores REST, servicios, entidades y lógica de combate.

# Sistema de Coordinación Estratégica - Castillo Infinito

## Requisitos
- Java 17+ 
- Maven
- MySQL

## Configuración
1. Crear base de datos `cazadores_db`.
2. Ajustar `application.properties` con usuario/contraseña MySQL.
3. Ejecutar:
   bash
   mvn clean spring-boot:run
